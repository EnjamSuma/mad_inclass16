
# Science Signal — In-Class Activity 16 (Class B)

**Student:** Suma Enjam  
**Course:** Mobile App Development  
**University:** Georgia State University

## Overview
Science Signal is a Flutter true/false quiz app that retrieves five medium-difficulty Science & Nature questions from Open Trivia Database.

## Features
- Firebase Authentication
- Five-question true/false quiz
- Answer feedback and score review
- Firestore create-once attempt storage
- Server-only verification
- Save recovery and collision handling
- Firestore security validation
- Graduate concurrency testing

## Technologies
Flutter, Dart, Firebase Authentication, Cloud Firestore, Open Trivia Database.

## How to Run
1. Install Flutter dependencies using `flutter pub get`.
2. Configure Firebase for your project.
3. Run `flutter run` on an Android device or Chrome.
4. Sign in, complete the quiz, and submit the result.

## Testing
The application includes T01–T12 validation scenarios and G01–G03 graduate investigations.
